# Câu hỏi thường gặp

## Tại sao nhạc không phát khi offline?

Tab Nhạc chỉ phát tệp âm thanh trên thiết bị. Quét thư viện cần quyền audio phù hợp với phiên bản Android; nếu không muốn cấp quyền, dùng nút chọn tệp để mở SAF và cấp quyền cho các URI đã chọn.

## Ứng dụng có gửi dữ liệu nhạc lên mạng không?

Không. Playback dùng URI cục bộ qua Media3. Quyền Internet còn lại phục vụ các nhà cung cấp AI được cấu hình riêng.

## Có cần API key để nghe nhạc không?

Không. Khóa API chỉ cần cho tính năng trò chuyện AI trực tuyến.

## Build release có được ký sẵn không?

Không. Khóa debug/release không nằm trong repository. Hãy quản lý signing key và mật khẩu ngoài source control.
